Краткое описание принципа работы ПО.

Бэкенд:
- При старте программы происходит чтение схемы станции и определение следующих ключевых элементов системы
    - количество приемников и диапазон (если задан) антенн, определение типа антенных систем - (всенаправленная или с наведением)
    - точка наблюдения
    - группа КА я наблюдения
    - загрузка харакетеристик известных КА из внешних источников и внутренних БД
    - список исключений
    - и т.д.
- Производится формирование списка пролетов спутников относительно точки наблюдения, формируется список частот и типов модуляии для настройки и получения данных
- Выбирается один из доступных радиотрактов
- Запускается процесс чтения и сбора данных с устройства,
- Перестройка частоты происходит в автоматическом режиме по заранее сформированному списку, квант времени для сбора данных подбирается в зависимости от частоты и модуляции, а так же типа сигналов
- Полученные данные прогоняются через pipeline цифровой обработки информации и демодуляции.
- Полученные пакеты полезной информации передаются на ui

UI:
По умолчанию запуск всегда производится в автоматическом режиме. Пользователь y UI имеет возможность переключать различные тракты в любых режимах.


### Режим работы "Авто"

В автоматическом режиме на ui выводится следующая информация:
 
 - картографичекая проекция с траекториями пролетающих КА над точкой наблюдения и индикацией зоны покрытия 
 - правая боковая панель с таблицей "план сеансов наблюдения" + графиком SkyView
 - нижняя панель (под картой) с отображением информации о передатчиках спутников

В данном режиме работы оператор может просто наблюдать за тем какие спутники пролетают над ним в текущий момент времени, изучать их характеристики, а так же выделять приорететный спутник для наблюдения (выбрать текущим)
В нижней панели пользователь может видеть результаты приема сигнала спутник благодара выводимым параметрам спутника, водопаду, а так же отдельной колонкеи результата демодуляции
В колонке результата демодуляци стоит выводить либо декодированные данные ТМИ, либо предоставлять возможность воспроизводить звук (например если это голосовая передача или морзянка). 
Для тяжелых данных типа - снимки метеоспуников, sstv и т.д. стоит выводить только тип данных и для работы с ними предлагать перейти в ручной режим.

В Автоматическом режиме действия и возможности оператора минимальны, он больше выступает наблюдателем

### Ручной режим

В данном режиме ПО работает в полуавтоматическом режиме.
UI выводит следующую информацию:

Секция 1.график панорамы на который выводится радиотехническая обстановка эфира - спектр + метки КА/передатчиков
    Для всенаправленной антенны:
      Формируем список из частот согласно плана сенасов спутников. Можно по текущему списку, можно с запасом +1 час, чтобы не дергать постоянно шкалу и масштаб графика.
      По этому списку происходит перестройка приемника и съем данных SDR->кольцевой буфер->DSP->демодуляция->UI(панорама) 
    Для направленой антенны с наведением:
      Алгоритм работы аналогичный, только либо вводим режим "автосопровождение" либо как-то рассчитываем точку наибольшего приема и наводим антенну туда. Либо наводим антенну в зенит
  - На панораме есть отметки по передатчикам КА. Видно кто вещает кто нет
  - Пользователь может или нажать на метку или вручную настроить приемник на эту частоту в отдельной панели настройки приемника (или нажать кнопку "сопровождение"). ПРи этом приемник должен чаще настраиваться или дольше стоять на это 
    выбранной частоте, чтобы получать свежие данные.

Секция 2. график спектра+водопад. Справа от них распологается панель с настройками приемника, фильтров (усиление,полоса и т.д). Так же тут есть управляющие элементы для выполнения записи сигнала
Пример:
    -----------------------------------------------
    |        спектр      |  панель с настройками  |                      
    |                    |  приемника, фильтров   |
    |--------------------|  запись сигнала        |
    |        водопад     |  и тд                  |
    -----------------------------------------------
 
Секция 3. Панель с вкладками

  - вкладка "Данные"/"Эфир"
    Содержит сводную тамблицу с общими данными по демодуляции. Можно сделать по аналогии как тамблица с передатчиками на нижней панели в режиме "авто". ТОлько убрать "Водопад" он здесь лишний.
    Предусмотреть возможность фильтрации
  - вкладка "антенны".
    Содержит графики Азимута и угла места мужде ними располагается информационно управляющая панель с вкладками:
    - наведение антенны
      - тип антены
      - настройка подключения + состояняи подключения
      - кнопки управления - автосопровождение, ручная настройка азимута угла места + кнопки старт/стоп и т.д. Референсы предоставлю 
    - график изменения угла места и и доплеровского сдвига
    - миниматюрная карта
    Пример:
     --------------------------------------------------------------------
    |                    |  вкладка 1/ вкладка2    |                    |                      
    |      график        |  упарвление антенной/   |      график        |
    |      азимута       |  графики/               |      угла места    |
    |                    |  минуатюра карты        |                    |
    ---------------------------------------------------------------------
  - вкладка "демодулятор"
    Содержит информационно-управляющую панель демодулятора. Предоставляет возможность вручную подбирать демодулятор, менять его настройки, смотреть параметры демодулятора, графики с информацицией о качестве деомдуляции и т.д.
    Так же содержит небольшое боковое окно в котором выводится результат демодуляции - для ТМИ это HEX текст, декодированный текст в читаемом представлении, для маяков и голосовых передатчиков это - потоквое аудио воспрозведение, для метеоснимкой - вывод картинки

        Пример:
     --------------------------------------------------------------------
    |                    |                         |                    |                      
    |    настройки       |                         |      результат     |
    |    демодулятора    |  графики                |                    |
    |                    |                         |                    |
    ---------------------------------------------------------------------
Секция 4 
Боковая панель "План сейансов" + SkyView

    ---------------------------------------------------------------
    | панорама                                    |               |
    ----------------------------------------------|               |
    |        спектр      |  панель с настройками  | план          |
    |                    |  приемника, фильтров   | сеансов       |
    |--------------------|  запись сигнала        |               |
    |        водопад     |                        |               |
    -----------------------------------------------               |
    |   Эфир |  антенна | демодулятор             | --------------|
    -----------------------------------------------               |
    |                                             |   skyview     |
    |        данные открытой                      |               |
    |                                             |               |
    ---------------------------------------------------------------

Таким образом алгоритм работы оператора следующий:
Оператор переводит режим работы станции в "Ручной" и он автоматически перебрасывается на окно где выводится - панорама, спектр+ водопад+ выбрана текущей вкладка "данные /эфир".
Пользователь либо на панораме,либо в таблице выбирает интересующий его КА (если у КА нескольк передатчиков, то ему придется дополнительно нужный выбирать на панораме). 
После чего приемник будет автоматически настроен на нужную частоту и пользователь будет видеть на графике спектра и водопада информаццию по сигналу.
При выборе определенного приемника автоматически  происходит переключение вкладки "данные /эфир" на вкладку "Демодулятор". 
При необходимости он может либо изменить настройки приемника, или поиграться с настройками демодуляции. оценить качество и результат. Измененные настройки демодулятора для КА/передатчика можно сохранять.
Если сигнал не знаком, то оператор может сделать запись сигнала. Во время записи сигнала приемник стоит на 1 частоте и перестройка отключена, "панорама" на паузе.
После записи сигнала оператор может перейти в режим "Анализ". Он описан в ADR-007-signal-lab-analysis.md.
