# ADR-012: Радиопрофиль КА

**Дата:** 2026-11-21  
**Статус:** Accepted  
**Связанные задачи:** RX-PROFILE-001  
**Связанные ADR:**
- ADR-011 (Реестр) — `transmitters` остаётся заявленным слоем; профиль лежит в `scout.db` рядом с `rx_visits`.
- ADR-009 (Опознание) — модуляция/скорость/рекомендованный демод из классификатора попадают в слой «обнаружено».
- ADR-004 (Режимы) — потребители: обход, демод «Авто», UI «Эфир» / План сеансов.

---

## 1. Контекст

Один передатчик сейчас описан в четырёх несвязанных местах: реестр `transmitters`, live `band_signals`, память «Авто», журнал `rx_visits`. После перезапуска и между стоянками накопленного знания нет: классификатор видит один режим, «Авто» пробует другой, обход держится на молчащем TX.

## 2. Решение

**Радиопрофиль КА** — одна запись на NORAD со списком передатчиков. Копится от стоянки к стоянке и от кадра к кадру, переживает перезапуск, служит источником для обхода, демода и UI.

### 2.1. Слои у передатчика

| Слой | Смысл | Источник |
|------|--------|----------|
| **Заявлено** | mode, baud, номинал | реестр `transmitters` (не копируется, не перезаписывается) |
| **Обнаружено** | модуляция, скорость, полоса, период маяка, сдвиг, уверенность, число подтверждений | классификатор / `band_signals` в конце стоянки |
| **Принято** | демод с верной CRC, счётчик кадров, время последнего | кадр телеметрии с NORAD |
| **Статистика** | стоянки всего / с энергией / с кадрами, лучший С/Ш, последний раз слышали | агрегация поверх стоянок и кадров |

Ключ передатчика: UUID из реестра; без UUID — номинальная частота с шагом 5 кГц (`freqplan.NearHz`).

Уровень КА — сводка: слышали / принимали / молчит, лучший передатчик, итоговые счётчики.

### 2.2. Действующий режим

Приоритет: **принято** (CRC) → **обнаружено** (≥3 одинаковых подтверждения модуляции и скорости) → **заявлено**.  
При расхождении UI показывает оба значения; таблица `transmitters` не меняется.

### 2.3. Точки записи

- Конец стоянки (`onSweepDwellEnd`): рядом с `Judge` / `AppendVisits` — обновление «обнаружено» и статистики.
- Кадр с верной CRC и известным NORAD — обновление «принято».

`rx_visits` остаётся сырым журналом; профиль — накопленная сводка поверх него.

### 2.4. Точки чтения

- Демод «Авто»: порядок кандидатов из действующего режима; pin переживает перезапуск.
- Стоянка: вид и длительность (в т.ч. период маяка) из действующего режима.
- Порядок обхода TX: свежая энергия в профиле — раньше молчащих; внутри стоянки частоту не меняем (один LO у RTL).
- UI: `GET /api/sat-radio` и SSE `sat_radio` — «Эфир», карточка сигнала, План сеансов.

### 2.5. Хранение

Пакет типов: `internal/rfprofile`. Персист: таблица `rf_profiles` в `scout.db` (схема v3), API через `registry.Registry`.

---

## 3. Последствия

- Один источник правды для обхода, «Авто» и таблиц UI.
- Реестр заявленных TX остаётся каноном каталога; расхождения видны явно.
- Миграция v2→v3 безопасна: новая таблица, `rx_visits` без изменений.
